# 연금 플래너 iOS 앱 구현 명세 (확정본 v1.0)

> 기획 명세(planner) + 사용자 확정 사항을 합친 문서. 개발·검증 모두 이 문서를 기준으로 한다.

## 0. 목표
연금 4가지(주택연금, 국민연금, 퇴직연금, 개인연금)를 입력하면, 은퇴 후 나이별 월수입(오늘 돈 가치, 세전)을
목표 월 500만원과 비교해 부족 구간과 부족액을 보여주는 오프라인 iOS 17+ SwiftUI 앱.
개인연금 월 납입액을 얼마 더 늘려야 부족분을 메우는지 역산하고, 은퇴를 1~5년 늦출 때의 효과도 보여준다.

## 2. 빌드 방식: Swift Package(계산 모듈) + Xcode App 템플릿에 파일 추가
- pbxproj를 손으로 쓰지 않는다. project.yml도 넣지 않는다.
- `PensionCore`는 Foundation만 import (SwiftUI/Charts/UIKit 금지). 앱에서 쓰는 타입/함수는 `public`.

- 키 `plan.v1`, `schemaVersion: Int` 포함, 디코딩은 `decodeIfPresent` + 기본값.
- 입력 변경 시 0.5초 디바운스 저장, 앱 실행 시 복원. 설정에 "모두 초기화".

## 5. 산식

### 5.1 공통 규칙
- 내부 원 단위 Double. 화면 입력/표기는 만원(×10,000).
- 나이는 정수 년. 나이 a 구간 = a세~a+1세 직전.
- 물가율 π, 할인계수 `D(a) = (1+π)^(a − 현재나이)`.
- 기본 함수 (Finance):
  - `fv(P,i,n) = P(1+i)^n`
  - `annuityFV(c,i,n) = c((1+i)^n − 1)/i`, i=0이면 `c·n`
  - `pmt(B,i,n) = B·i/(1 − (1+i)^(−n))`, i=0이면 `B/n` (|i|<1e-12를 0으로 취급)
- 유효 수령개월 `n = 12 × min(수령기간, 기대수명 − 수령시작나이)`. n ≤ 0이면 월액 0 + 경고.

### 5.2 물가연동 수령 (U5) — 퇴직·개인연금 공통
- 수령 시작 나이 s, 수령 시작 시점 적립금(명목) `B_start`, 수령 중 연수익률 r_p.
- 오늘 돈 가치 적립금 `B_real = B_start / D(s)`.
- 실질 월이율 `j = (1 + r_p/12) / (1+π)^(1/12) − 1` (매달 물가만큼 수령액이 오르는 것으로 근사).
- **오늘 돈 가치 월 수령액 `R = pmt(B_real, j, n)`** — 수령 기간 내 모든 나이에서 동일.
- 명목 월액(참고 표시용) 나이 a의 첫 달 ≈ `R × D(a)`.
- π = 0이면 j = r_p/12 로 기존 고정액 계산과 같아진다.
- j가 음수여도 pmt 식은 유효(분모 0 아님). |j|<1e-12만 0 분기.

### 5.3 공통 입력
| 항목 | 기본(예시) | 범위 |
|---|---|---|
| 현재 나이 | 40 | 20~80 |
| 은퇴 나이 | 60 | ≥ 현재나이 |
| 기대수명 | 90 | > 은퇴나이 |
| 물가상승률 | 2.0% | −2~10% |
| 목표 월수입 | 500만원 | >0 |

### 5.4 퇴직연금 (DC/IRP)
입력(기본): 포함 ON, 방식 [DC/IRP 계산 | 은퇴 시점 적립금 직접 입력], 현재 적립금 3,000만, 연봉 5,000만, 연봉 상승률 3%,
연간 적립률 8.333%(1/12), 적립 수익률 4%, 수령 시작 = 은퇴나이(기본 60, "은퇴 나이와 같게" 토글 기본 ON), 수령기간 20년, 수령 중 수익률 3%.
- 적립: N = 12×(은퇴−현재). m=0..N−1: `bal = bal(1+i_acc) + 연봉(1+g)^⌊m/12⌋ × 적립률/12`. → `B_ret`.
- 직접입력 모드: `B_ret` = 입력값(은퇴 시점 명목).
- 연기: 시작 s > 은퇴 R이면 `B_start = B_ret(1+i_acc)^(12(s−R))`.
- 수령: 5.2. 나이 s ~ s+유효수령년수−1 에서 오늘 돈 월액 R.
- 수령 시작 < 은퇴나이 → 오류.

### 5.5 개인연금 (연금저축/IRP 개인납입)
입력(기본): 포함 ON, 현재 잔액 0, 월 납입 30만, 납입 종료 나이 60("은퇴 나이와 같게" 토글 기본 ON), 운용수익률 4%,
수령 시작 60(토글 기본 ON), 수령기간 20년, 수령 중 수익률 3%.
- n_c = 12×max(0, 납입종료−현재). `B_c = fv(잔액,i,n_c) + annuityFV(월납입,i,n_c)`. 수령 시작까지 fv로 키움 → B_start.
- 수령: 5.2.
- 오류: 수령 시작 < 납입 종료, 수령 시작 < 은퇴나이. 참고 경고(U11): 수령 시작 < 55 또는 수령기간 < 10년 ("일반적인 기준이며 최종 확인 필요").

### 5.6 주택연금
입력: 포함 OFF(기본), 모드 [(a) 공사 조회값 직접 입력(기본) | (b) 대략 추정], 가입(수령 시작) 나이 기본 = 은퇴나이.
- (a) 가입 시점 명목 첫 월지급액 P (U8). 기본 빈값.
- (b) 현재 주택가격, 주택가격 상승률(기본 0%), 가격표.
  `H = 현재가격(1+g)^max(0,가입−현재)`, `H' = min(H, 상한)`, `P = H'/1억 × 표[가입나이]`.
  가격표 구조: rows [나이 → 1억당 월지급금(원)], priceCap, source, asOfDate, confidence(A~F).
  **기본값 전부 빈칸**, source/asOfDate "확인할 수 없음", confidence F. 실제 지급액 표 하드코딩 금지. 보간 금지 → 표에 나이 값 없으면 "표에 해당 나이 값을 입력하세요" 오류.
- 수령 (U5 물가연동): 오늘 돈 월액 `R_h = P / D(가입나이)`, 가입나이 ~ 기대수명−1 모든 나이 동일.
- 화면 안내: "실제 주택연금 정액형은 금액이 고정되어 물가만큼 늘지 않습니다. 이 앱은 사용자 선택에 따라 물가연동으로 가정하므로 실제보다 높게 보일 수 있습니다. 정확한 값은 한국주택금융공사 예상연금 조회를 권장합니다."

### 5.7 국민연금
입력: 월 예상 수령액(오늘 돈 가치, 기본 0), 시작 나이(기본 65). 나이 ≥ 시작이면 입력값 그대로.

### 5.8 나이별 합계 (IncomeTimeline)
- a = 은퇴나이 … 기대수명−1. 4종 오늘 돈 월액, 합계, `부족(a)=max(0, 목표−합계)`.
- 은퇴 전 시작하는 연금(국민·주택)은 은퇴나이부터 표시. 합계 0인 나이 = 공백 구간.

### 5.9 요약 / 메우기 / 은퇴 연기 (GapAnalyzer)
- 달성: 모든 a에서 합계 ≥ 목표.
- 부족 구간: 부족>0인 연속 나이 묶음 (시작~끝, 평균·최대 부족).
- 가장 부족한 구간(최대 부족액 나이가 속한 구간, 그 최대값) + 가장 덜 부족한 구간(구간별 최대 부족이 가장 작은 구간) (U9).
- 개인연금 증액 역산 (U6):
  1. W = 개인연금 오늘 돈 월액 > 0 인 나이. 개인연금 포함 OFF이거나 W 공집합이면, 기존 입력으로 W를 정의할 수 없으므로 "현재 개인연금 수령 설정 기준(시작나이, 기간)"으로 W를 계산하되 포함 OFF면 "개인연금을 켜면 계산됩니다" 문구.
  2. Δ = max_{a∈W} 부족(a)  (오늘 돈 기준; 물가연동이라 W 안에서 개인연금 기여는 일정).
  3. p1 = 월 납입 1원·잔액 0일 때의 오늘 돈 월 수령액. 추가 월 납입 = Δ / p1 (폐쇄해). 테스트에서 이분법 결과와 ±100원 비교.
  4. W 밖 부족이 남으면 "개인연금으로 메울 수 없는 구간: N~M세" 문구 필수.
  - 추가 월 납입액은 명목(지금부터 납입 종료까지 매달 고정)임을 화면에 표기.
- 은퇴 연기 표 (U7): k=1..5, 은퇴=R+k로 재계산. 퇴직연금 수령시작/개인연금 납입종료·수령시작은 "은퇴 나이와 같게" 토글 ON이면 R+k를 따르고, OFF면 max(원래값, R+k). 국민·주택은 그대로(주택 가입나이도 은퇴와 같게 토글 ON이면 따라감). 출력 (은퇴나이, 최대 부족액, 달성 여부). 기대수명 ≤ R+k이면 해당 행 생략.

### 5.10 경계조건
수익률 0 분기, π=0 → D=1, 은퇴=현재 → N=0, 은퇴<현재 오류, 수령시작 ≥ 기대수명 → 0+경고,
수령기간 초과 → min으로 축소, 금액 음수 불가, 수익률·상승률 −10~30%, 포함 OFF → 0·차트 숨김,
NaN/무한대 → "계산할 수 없음"(크래시 금지). 모든 메시지 쉬운 한국어.
